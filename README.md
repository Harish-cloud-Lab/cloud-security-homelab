# cloud-security-homelab
A self-directed home lab where I practice cloud security by running a small
environment the way a real company would: building infrastructure as code,
scanning it for problems, monitoring logs, and documenting what I find and fix.

## Goals
- Build cloud infrastructure securely with Terraform
- Scan code and containers for misconfigurations
- Practice detection and incident response
- Document daily and weekly work

## Tools (planned)
Terraform, Docker, Kubernetes, Checkov, Trivy, Prowler, Wazuh
